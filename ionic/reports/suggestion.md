# Reports — Suggestions

- Defer `format=csv`/share-sheet in v1 — platform share quirks eat days; numbers-on-glass is the actual need.
- If the backend report set is large, ship only 2–3 high-value keys in v1 (attendance summary + task completion) — web covers the rest.
- Audit viewer filter set should mirror the web audit page's filter controls exactly (same param names) — shared filter-config registry applies here too.
