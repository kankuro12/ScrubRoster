# Attendance — Suggestions

- Default clock-in to the day's active shift (me/shifts) automatically; show which shift is being clocked into before the tap — avoids wrong-shift events.
- Surface `distance_from_property_meters` + `effective_radius_meters` from the clock response — transparency builds trust with field crew.
- Keep the Clock tab as the home tab for cleaners — it's the highest-frequency action (matches web emphasis on status rails).
