# Properties — Suggestions

- `missing_coords`/`unassigned` pills map to the same buttons web shows in its property toolbar — keep the exact label wording for cross-platform recognition.
- Reference lists (categories/tags) belong in the foundation cache layer, not per-screen — one fetch per session.
- Retry-geocode is a tap-and-wait async op server-side; show a spinner + allow leaving the screen (server finishes anyway).
