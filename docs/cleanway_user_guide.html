Module 03 · Task Operations

3. Detailed Task Management Workflows

Action 3.1: Adding a New Cleaning Task

Purpose: Schedule a new cleaning shift for a site location and assign it to a cleaner or cleaning crew.

UI Form Field LabelForm Control TypeRequired?User Guidance & Options
Task TitleText InputYESDescriptive headline e.g. Daily Evening Office Sanitize.
Target Property LocationDropdownYESSelect property location where work takes place.
Assign Work ToSelectorYESChoose Individual Cleaner or Cleaning Team.
Assigned Cleaner / TeamDropdownYESSelect cleaner name or team name.
Scheduled Start Date & TimeDate-Time PickerYESPlanned shift start time.
Scheduled End DeadlineDate-Time PickerYESShift completion deadline.
Priority LevelSelect PillsYESLow, Medium, High, Critical (Default: Medium).
Require Supervisor Quality ApprovalCheckboxOptionalCheck box to require supervisor approval before task closes.
Attach Checklist TemplateDropdownOptionalSelect subtask inspection template.
Step-by-Step UI Clicks:
  1. Navigate to Tasks on the navigation sidebar.
  2. Click the + Create Task button at top-right.
  3. Fill in Task Title, Target Property, Assignee, Scheduled Start & End times.
  4. Select a Checklist Template and check Require Supervisor Approval if quality inspection is mandatory.
  5. Click Create & Publish Task. System generates reference tracking code (e.g. TSK-20260807-0014) and sends an instant push notification to the cleaner.

Action 3.2: Editing an Existing Task

Purpose: Modify scheduled start times, change assigned staff, or update shift notes for tasks in assigned or in_progress state.

Step-by-Step UI Clicks:
  1. Open Tasks screen.
  2. Click the Actions (...) button next to the task $\rightarrow$ select Edit Task.
  3. Update desired fields (e.g. extension of deadline, new cleaner assignment, or updated notes).
  4. Click Save Changes. System updates record and notifies new assignee.

Action 3.3: Cancelling a Task

Step-by-Step UI Clicks:
  1. Open Tasks $\rightarrow$ click Actions (...) $\rightarrow$ select Cancel Task.
  2. Type the cancellation reason (e.g. "Client cancelled shift due to public holiday").
  3. Click Confirm Cancellation. Task status updates to cancelled.
Module 04 · Field Staff

4. Cleaner Shift Operations

1 Shift Clock-In with GPS Radius Check

Tap Attendance $\rightarrow$ tap Clock In. Smartphone GPS checks distance $\le$ permitted radius (e.g. 150m).

  • Within Radius (e.g. 84m): Tap Confirm Clock In. Shift starts immediately.
  • Outside Radius (e.g. 220m): Complete the Override Reason Justification text box (e.g. "Parked 200m away in alley loading bay") $\rightarrow$ tap Submit Override Request.

2 Checklist Subtasks & Photo Uploads

Open My Tasks $\rightarrow$ tap today's assigned task $\rightarrow$ tap Start Cleaning. Complete subtasks (Pass/Fail, Yes/No, Numeric meter readings). Tap Upload Before Photo and Upload After Photo for mandatory evidence items, then click Submit Task for Supervisor Review.

Module 05 · Management

5. Supervisor Quality Review & Approvals

Open Quality Approvals sidebar menu to inspect pending tasks. Review cleaner check-in GPS distance, check subtask answers, click before/after photos to enlarge, then take action:

Approve Task

Click Approve & Complete Task. Sets status to approved, alerts cleaner via push notification, and writes audit log.

Request Rework

Type specific instructions into Rework Notes (e.g. "Re-mop lobby glass door") $\rightarrow$ click Request Rework. Returns task to cleaner.
